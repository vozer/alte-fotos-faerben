# Windows repair test release

Release: `v0.2.3-windows-test-1` (GitHub prerelease).

Release page: <https://github.com/vozer/alte-fotos-faerben/releases/tag/v0.2.3-windows-test-1>

The 0.1.0 and 0.2.3 Windows installers contain uninstallers that fail the NSIS
integrity check. Windows then reports that the app cannot close, even when no
app process is running. The installer retries the failed uninstaller and shows
the misleading close-app message.

The prerelease includes a corrected 0.1.0 uninstaller and a test installer.
The corrected uninstaller has the same program bytes as the published 0.1.0
uninstaller. Its integrity checksum is valid. The test installer uses the same
NSIS icon for its installer and uninstaller, which avoids the cross-build bug.

The Windows user confirmed that the corrected uninstaller let the 0.1.0 app
reach uninstall. The user has not confirmed installing the test installer.
Model reuse, offline processing, colorization, and the test release's own
uninstall remain unverified on Windows. Do not call this a stable release.
