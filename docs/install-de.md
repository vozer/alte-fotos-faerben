# Alte Fotos färben installieren

## Installer herunterladen

Wählen Sie den passenden Download für Ihren Computer:

- [Windows 10 oder 11 (x64), etwa 150 MB](https://github.com/vozer/alte-fotos-faerben/releases/download/v0.2.3/DeOldify-Windows-x64-Setup.exe)
- [Mac mit Apple-Chip, etwa 165 MB](https://github.com/vozer/alte-fotos-faerben/releases/download/v0.2.3/DeOldify-macOS-arm64.dmg)

Die Dateien liegen nach dem Herunterladen meistens im Ordner „Downloads“.

Die Links oben führen zur Version 0.2.3.

## Windows

1. Öffnen Sie `DeOldify-Windows-x64-Setup.exe` im Ordner „Downloads“.
2. Folgen Sie den Schritten auf dem Bildschirm.
3. Falls Windows eine Sicherheitsmeldung zeigt, wählen Sie „Weitere Informationen“ und danach
   „Trotzdem ausführen“.
4. Starten Sie „Alte Fotos färben“ über das Symbol auf dem Desktop.

### Update auf Version 0.2.3

1. Schließen Sie „Alte Fotos färben“.
2. Öffnen Sie das neue `DeOldify-Windows-x64-Setup.exe`.
3. Installieren Sie das Update über die vorhandene App. Deinstallieren Sie die alte App nicht zuerst.
4. Starten Sie die App über das Symbol auf dem Desktop.

Die gültigen Modelle bleiben auf dem Computer. Die neue App lädt sie nicht
erneut herunter. Sie lädt nur ein fehlendes oder beschädigtes Modell neu.

## Mac

1. Öffnen Sie `DeOldify-macOS-arm64.dmg` im Ordner „Downloads“.
2. Ziehen Sie „Alte Fotos färben“ in den Ordner „Programme“.
3. Öffnen Sie das Programm. Wenn macOS eine Sicherheitsmeldung zeigt, klicken
   Sie mit der rechten Maustaste auf das Programm und wählen Sie „Öffnen“.

DeOldify Stable ist vorausgewählt und färbt eher zurückhaltend. Wenn ein Foto
zu grau wirkt, wählen Sie DDColor Tiny. Tiny macht die Farben kräftiger, kann
aber manchmal falsche Farbflächen hinzufügen. Sie können dasselbe Foto mit
beiden Modellen färben. DeOldify Stable benötigt 873 MB. DDColor Tiny benötigt
222 MB. Jedes Modell lädt beim ersten Färben herunter und funktioniert danach
offline. Mit beiden Modellen braucht die App rund 1,1 GB. Ihre Fotos bleiben
auf diesem Computer.

Die App öffnet bis zu 20 JPEG- und PNG-Fotos auf einmal. Größere Fotos müssen
Sie vorher verkleinern. Für jedes Foto entstehen beide Modellergebnisse.
Bearbeiten Sie jedes Ergebnis einzeln und wählen Sie für jedes Foto eines aus.
Speichern Sie einzelne Bilder oder alle ausgewählten Bilder in einem Ordner.

Unter „Farben anpassen“ finden Sie Farbintensität, Helligkeit, Wärme, Farbton,
Tonwertkorrektur, ein RGB-Histogramm und Farbkurven für alle Farben, Rot, Grün
und Blau. Die App speichert farbige Kopien als PNG. Das Original bleibt erhalten.
