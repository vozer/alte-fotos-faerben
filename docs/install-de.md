# Alte Fotos färben installieren

## Windows

1. Öffnen Sie `DeOldify-Windows-x64-Setup.exe`.
2. Folgen Sie den Schritten auf dem Bildschirm.
3. Falls Windows nachfragt, wählen Sie „Weitere Informationen“ und danach
   „Trotzdem ausführen“.
4. Starten Sie „Alte Fotos färben“ über das Desktop-Symbol.

## Mac

1. Öffnen Sie `DeOldify-macOS-arm64.dmg`.
2. Ziehen Sie „Alte Fotos färben“ in den Ordner „Programme“.
3. Öffnen Sie das Programm. Wenn macOS es blockiert, klicken Sie mit der
   rechten Maustaste darauf und wählen Sie „Öffnen“.

DeOldify Stable ist vorausgewählt und färbt eher zurückhaltend. Wenn ein Foto
zu grau wirkt, wählen Sie DDColor Tiny. Tiny macht die Farben kräftiger, kann
aber manchmal falsche Farbflächen hinzufügen. Sie können dasselbe Foto mit
beiden Modellen färben. DeOldify Stable benötigt 873 MB. DDColor Tiny benötigt
222 MB. Jedes Modell lädt beim ersten Färben herunter und funktioniert danach
offline. Mit beiden Modellen braucht die App rund 1,1 GB. Ihre Fotos bleiben
auf diesem Computer.

Die App öffnet JPEG- und PNG-Fotos bis 24 Megapixel. Größere Fotos müssen Sie
vorher verkleinern.
